## 🌟 About Me  
I'm a backend software engineer focused on building **scalable, reliable, and maintainable systems** using modern backend technologies and clean architectural principles.

I work primarily with **.NET** and **Node.js (NestJS)** and have hands-on experience designing **microservices-based systems**, integrating **payment gateways**, implementing **authentication & authorization**, and working with **asynchronous messaging**.

My background in **computer science fundamentals** (data structures, OOP, concurrency, networking, and system design) allows me to reason deeply about performance trade-offs, scalability, and fault tolerance — not just writing code, but understanding *why* it works.

I value **clean code**, **pragmatic engineering**, and **continuous learning**, and I enjoy digging into how things work under the hood — from HTTP internals to OS-level concepts.
